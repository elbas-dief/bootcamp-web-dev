6. Proses Kembalikan Buku borrowings/return.php
📚 Perpustakaan
Buku Peminjaman Admin ▾ Logout
⚙️
Tidak ada tampilan UI
Hanya proses PHP (POST handler) + redirect
Alur saat tombol "↩ Kembalikan" diklik:
1
Terima id borrowing dari POST/GET
2
Ambil book_id dari tabel borrowings
3
UPDATE borrowings: status = 'dikembalikan', return_date = CURDATE()
4
UPDATE books: stock = stock + 1
5
Redirect → borrowings/index.php

📌 Catatan

  • Tidak perlu form — langsung proses saat tombol diklik
  • Tetap pasang auth_check.php di baris pertama
  • Kedua UPDATE harus berhasil — stok & status harus sinkron
  • Gunakan prepared statements untuk keamanan
